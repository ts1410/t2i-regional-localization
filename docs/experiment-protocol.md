# Experiment Protocol

This file describes the controlled research workflow used for the pilot.

1. Read the project framework and campaign brief.
2. Confirm that the product reference image is the same across all runs.
3. Select a model and a single region/festival combination.
4. Construct the image-generation prompt using the framework and campaign brief.
5. Generate the image without modifying the controlled campaign or framework variables.
6. Save experiment metadata and output path.
7. Compare the image against the same campaign objective in the target region.
8. Only after review should the researcher expand to other models or regions.

The pilot is exploratory. The final formal human evaluation will use 8–10 participants and is separate from generation.
